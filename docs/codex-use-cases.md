# Codex Use Cases

Codex can help Rushd become easier to maintain over time without losing the existing Arabic-first UX.

Useful work includes:

- Refactor the single-file HTML into smaller modules while preserving behavior.
- Add and expand tests for budget, safe-to-spend, recurring template, month-end settlement, import/export, and vault calculations.
- Improve RTL layout and mixed Arabic/English currency formatting.
- Tighten mobile responsiveness and modal behavior.
- Improve export/import validation and backup safety.
- Add charts or improve current statistics visualization.
- Add recurring expense and obligation support more cleanly.
- Improve accessibility and reduced-motion behavior.
- Review pull requests for privacy, financial-data handling, and misleading product claims.
- Generate documentation from code as the architecture changes.
- Help plan a controlled React/Vite or Vue/Vite migration if the project outgrows the static file.

Six months of Codex/ChatGPT Pro would be useful because the project has real product surface area, a large single-file codebase, and many reviewable improvements that benefit from iterative coding, testing, and documentation.
